Contextual chunking pipeline

Entry point:

```powershell
.\venv\Scripts\python.exe -m src.preprocess.pipeline `
  --input data\raw `
  --output data\processed\preprocess_output `
  --context-batch-size 20 `
  --openrouter-min-interval 3 `
  --openrouter-max-requests 40
```

Required environment variable:

```text
OPENROUTER_API_KEY=...
OPENROUTER_MIN_INTERVAL_SECONDS=3
OPENROUTER_MAX_REQUESTS_PER_RUN=40
```

Rate-limit protection:

- Up to 20 uncached chunks are sent in one contextualization request.
- Pending chunks are batched across page boundaries; only the final partial
  batch contains fewer than 20 chunks.
- Requests from chat and rerank clients share one in-process limiter.
- The default pacing is one request every 3 seconds.
- At most 40 HTTP attempts are allowed per Python run by default.
- HTTP 429, 408, and transient 5xx responses use exponential backoff with
  jitter and honor the `Retry-After` response header.
- Contextual preprocessing switches to deterministic page/heading context when
  the request budget is exhausted or OpenRouter remains unavailable.
- Existing OpenRouter responses are cached and do not consume another request.

Set `--openrouter-max-requests 0` for no per-run cap. This is not recommended
for free API accounts. Use `--strict-context` to stop instead of falling back.

Progress bars show:

- PDF files completed.
- Pages completed in the current PDF.
- Contextual chunks completed on the current page.
- API attempts, pending chunks, cache hits, and fallback contexts.

Use `--no-progress` in non-interactive jobs.

The pipeline has one text chunking flow:

1. Extract and normalize PDF text blocks.
2. Keep heading and paragraph structure when splitting oversized text.
3. Send each text chunk with its page context to
   `google/gemma-4-31b-it:free` through OpenRouter.
4. Prefix the generated context sentence to the original chunk.
5. Cache contextualization responses under
   `data/cache/contextual_chunking/openrouter_contexts.json`.
6. Write text, table, and visual chunks to
   `data/processed/preprocess_output/<document>/chunks.jsonl`.

Main modules:

- `pipeline.py`: command-line interface.
- `document.py`: PDF processing and output writing.
- `contextual_chunking.py`: Gemma contextualization and cache.
- `text.py`: structural splitting used by contextual chunking.
- `tables.py`, `visuals.py`, `geometry.py`: non-text extraction helpers.
